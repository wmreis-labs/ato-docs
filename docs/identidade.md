# ATO — identidade visual

Produto: plataforma de agentes inteligentes que automatizam processos, executam tarefas e acompanham resultados.

Tagline: **Inteligência que faz acontecer.**

Domínio de referência: `ato.testto.com.br`

## Marca

- Nome: **ATO**
- Símbolo: “A” geométrico (sem barra cruzada), com nós/circuitos no mark monocromático e gradiente azul→ciano no mark colorido
- Wordmark: ATO em sans-serif bold; o A acompanha a geometria do símbolo

![Logo mark ATO](assets/ato-logo-mark.svg){ width="120" }

Assets PNG de marca (`ato-brand-board.png`, `ato-logo-mark.png`) ficam no Project store (`media/`) e podem ser commitados em `docs/assets/` quando houver push de binários.

## Paleta

| Token | Hex | Uso |
| --- | --- | --- |
| Blue principal | `#2563EB` | Ação primária, confiança, links |
| Blue claro | `#3B82F6` | Hover, destaques secundários |
| Ciano | `#06B6D4` | Inovação, movimento, acentos de gradiente |
| Grafite | `#0F172A` | Fundos escuros, sidebar, marca |
| Cinza | `#64748B` | Texto secundário, ícones neutros |
| Verde sucesso | `#10B981` | Operação concluída |
| Âmbar atenção | `#F59E0B` | Atenção / pendência |
| Erro | vermelho semântico (ex.: `#EF4444`) | Erro no processo |

Gradiente de marca (logo / CTAs fortes): blue claro → blue principal → ciano.

## Tipografia

- Família: **Plus Jakarta Sans**
- Display / títulos: SemiBold–Bold
- Corpo: Regular–Medium
- Ênfase na tagline: “acontecer.” em blue principal

## Elementos de UI

- Cards com cantos arredondados; em superfícies de marca, vidro (borda leve + blur) sobre fundo grafite
- Badges de status: sucesso (verde), atenção (âmbar), erro (vermelho)
- Gráficos: linha azul com área suave; badge de variação (ex.: +42%)
- Ícones de linha (automação, execução, resultados)
- Botões primários em blue / gradiente; cantos arredondados (pill ou ~10–12px)

## Relação com o console

- As 14 telas de Operador / Admin da plataforma eleita continuam como referência de **estrutura e fluxos**
- A marca **Atende** do mock de referência é substituída por **ATO** (logo, nome, cores, tipografia)
- Tema do console: fundo claro de conteúdo + sidebar grafite; tokens MUI 5 mapeados para a paleta acima
- Front: React + MUI 5 + Plus Jakarta Sans

## Mensagens de produto (brand board)

- Execute tarefas

- Atendimento inteligente · operações automatizadas · resultados mensuráveis
